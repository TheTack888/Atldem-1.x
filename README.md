# Atldem (Athlon + Radeon)

> 一个由高中生纯手工从零手搓的微型语言模型，专为无 GPU、无云端的“废土硬件”打造。

## 🚀 项目背景
在没有顶级电脑、也没有预算购买云端 API 的情况下，我通过一台 2019 年的 vivo 手机（骁龙 675），使用纯 Python 和 NumPy 库，从零手写了 RNN 的前向传播、反向传播和梯度下降。
没有使用 PyTorch，没有 CUDA。主打一个“最低的投入，最大的产出”。

## ✨ 核心特性
- **纯 NumPy 实现**：零深度学习框架依赖，极简，硬核。
- **全本地运行**：不需要联网，断网也能跑。
- **基础问答能力**：内置了简单的问答语料，支持简单的多轮对话（指令微调雏形）。
- **权重持久化**：支持使用 `.npz` 保存和加载模型权重，训练一次，永久唤醒。

## 🛠️ 运行指南
1. 安装 Python 环境 (开发环境为 Android Termux + Python 3)。
2. 安装依赖：`pip install numpy`
3. 运行脚本：`python atldem1.11.py`

## ⚠️ 架构局限（Next Step）
由于采用的是原生 RNN 架构，模型存在严重的“金鱼记忆”（梯度消失），长文本会出现乱码（比如 `1de最可？`）。
**下一步计划**：手写极简的 Self-Attention（Transformer 架构），进行降维打击，开启 Atldem 2.0 时代。
